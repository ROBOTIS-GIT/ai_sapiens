0.2.0 (2026-08-26)
------------------
* Added a MuJoCo ``ros2_control`` system interface for AI Sapiens K1.
* Exposed the same joint, IMU, and HAT state and command interfaces used by the
  real hardware stack.
* Added optional interactive viewer and gantry services for setting height,
  attaching, and releasing the robot.
