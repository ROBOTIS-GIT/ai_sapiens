0.1.0 (2026-07-24)
------------------
* Added the realtime control loop running ONNX policies and publishing joint impedance commands.
* Added the mode state machine with teleop-driven transitions, startup gating, and layered failsafes.
* Added Manual/API authority arbitration with warmup, heartbeat watchdog, and release blocking.
* Added mimic policy runtimes with reference-motion playback and squat and dance assets.
* Added the Radiomaster Pocket teleop input plugin.
* Added YAML-driven state, behavior, and policy asset configuration with startup validation.
* Documented the runtime in a package README and added unit and mode transition smoke tests.
